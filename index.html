Research Context: This interactive visualization is part of the Master's thesis Yilandiloglu, E. (2025). Mapping Orientalism: A quantitative study of eighteenth-century British travel writing [Master’s thesis, University of Helsinki].

Data Source: Eighteenth Century Collections Online (ECCO), filtered for geographic entity mentions in travel narratives published 1700-1800. Because the data is OCR'd, you may encounter some noisy passages. Also, since the place names were linked to locations automatically, there may be erroneously linked mentions.

Methodology: Named Entity Recognition (NER), sentiment analysis, and geographic information system (GIS) integration.

For citation: Yılandiloğlu, E. (2025). Mapping Orientalism: A Quantitative Study of Eighteenth-Century British Travel Writing. [Master's thesis, University of Helsinki].

How to use this interface

The map

Each point marks a place mentioned in the corpus. Click a point to open its full details in the right-hand panel. The map always reflects your current filters and search. Marker size can be made proportional to how often a place is mentioned (see Layers → Base Markers).

Filters tab

  • In each filter, click a value to select it, click again to deselect. You can select several values.
  • Within one filter, selected values are combined with OR (any match); across different filters they are combined with AND (all must match).
  • Use a filter's search box to narrow a long list — e.g. type an ECCO ID, ESTC ID, place, or category, then click the value you want.
  • Year range limits results to a publication-year window.
  • Reset all filters clears every selection and the search.
  • The Dataset Summary at the bottom updates live (records, locations, works, authors, temporal range).

Full-text search

  • The Full-text search box finds mentions whose text contains your term; results are combined with your active filters.
  • Search in chooses which text layer is searched: Short snippet, Wide snippet, or Full chunk (see the snippet types below).
  • Multi-word queries return mentions that contain all the words. A running match count is shown beneath the box.

Layers tab

  • Active Layers — tick Count Heatmap, Sentiment Layer, or Density Layer to add them to the map. Each has a collapsible Settings panel directly beneath its checkbox (heatmap radius/blur/gradient, sentiment ring colours, density opacity, etc.).
  • Base Markers — set marker colour and size, and choose Size by to scale markers by mention, work, or author count.
  • All layers recompute from the data currently shown by your filters and search.

Right panel — Location Details

Clicking a point fills this panel with, in order: the place name, type and description; a Statistical Overview (total mentions, distinct works, authors, decades); Metadata (temporal coverage, authors, author/mention gender distribution); a Sentiment Distribution bar chart; and the Textual Evidence — the actual mentions grouped by work and ordered chronologically.

The three snippet views

Every mention is available at three text scopes:

  • Short snippet — sentence-level: the single sentence in which the mention occurs. This is shown by default and is the quickest to read.
  • Wide snippet (Expand wider context) — a broad passage spanning roughly ten sentences before to ten sentences after the mention. This is the fullest context and the largest text. This can be useful when you search for a term that does not co-occur with a place name but mentioned in the adjacent sentences.
  • Full snippet (Expand full snippet) — the 128-token text chunk the mention was extracted from during processing.

In each mention the entity is highlighted, and its sentiment label and score are shown above the text.

For further technical details, please see Yılandiloğlu, E. (2025). Mapping Orientalism: A quantitative study of eighteenth-century British travel writing [Master’s thesis, University of Helsinki].
