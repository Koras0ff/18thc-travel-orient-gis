# Mapping Orientalism — Interactive Visualization

Static site for the interactive map from the thesis
*"Mapping Orientalism: A Quantitative Study of Eighteenth-Century British Travel Writing"*
(Enes Yilandiloglu, University of Helsinki).

## Contents
- `index.html` — the visualization (Leaflet + vanilla JS, no build step)
- `data.js` — normalized startup payload (map, filters, short snippets)
- `data/context/` — wide + full snippet text, loaded on demand when expanded
- `data/index/` — full-text search index shards, loaded per query
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Viewing
Just open `index.html` in a browser (double-click it). Data is loaded through
`<script>` tags rather than fetch(), and the heavy text + search index are
fetched lazily, so it works when opened directly from disk (file://) — no local
server required. Keep the `data/` folder next to `index.html`.

## Publishing to GitHub Pages
1. Commit this folder to your repository.
2. In the repository, go to Settings -> Pages.
3. Under "Build and deployment", set Source to "Deploy from a branch",
   then choose the branch and this folder as the source.
4. Save. Your map will be served at the URL shown on that page.

## Rebuilding the data
The dataset is regenerated by `updated_visualizer.py`, which reads the source
CSVs and writes `index.html` + `data.js` into this folder.
