# Mapping Orientalism

This interface was built from the thesis
Yılandiloğlu, E. (2025). Mapping Orientalism: A quantitative study of eighteenth-century British travel writing [Master’s thesis, University of Helsinki]. Helda. https://helda.helsinki.fi/items/e5b76e15-ac6e-45ca-b8f9-11be5ec6ce28

After completing the initial work for my thesis, I improved the interface by enhancing the filtering options and visual design.
To view this updated interface, you can just open `[index.html](https://koras0ff.github.io/18thc-travel-orient-gis/)` in a browser.

## Previous version
The previous version of this interface can be found in index_legacy.html. It includes only 5,000 mentions and does not have the full data. It is stored here for the purpose of archiving.
